## Task

Extract patterns that can help future investigations. Focus on:

1. **Error Pattern**: A generalizable template for matching similar errors
   - What makes this error recognizable?
   - What contextual clues indicate this type of error?

2. **Root Cause Pattern**: A template for the root cause
   - How should this type of root cause be described?
   - What evidence typically confirms it?

3. **Evidence Patterns**: What types of evidence were most useful
   - Which queries yielded strong results?
   - Where was strong evidence found?

4. **Investigation Strategy**: What approach worked best
   - Was code-centric or log-centric analysis more effective?
   - What shortcuts could be taken next time?

5. **Calibration Data**: For improving confidence estimates
   - Was the stated confidence accurate?
   - What would indicate higher/lower confidence?
