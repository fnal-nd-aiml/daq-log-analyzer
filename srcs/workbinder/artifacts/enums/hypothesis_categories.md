## Hypothesis Categories

Root causes are classified into one of these categories:

- **hardware**: Device communication failures, timeouts, data corruption, physical issues
- **software**: Memory issues, logic errors, race conditions, null pointers, exceptions
- **configuration**: Mismatched settings, invalid parameters, incorrect paths, missing values
- **timing**: Synchronization issues, deadlines missed, race windows, ordering problems
- **resource**: Out of memory, disk full, network congestion, connection limits, buffer overflow
- **unknown**: Cause cannot be categorized or requires further investigation
